# Публикация APK

Публикуйте исходники и устанавливаемый APK в репозитории `fitherdusk/Vocabulary-` на GitHub.

Для каждой версии проверьте номер версии и подпись APK. Сохраните сборку в `downloads/OfflineVocabulary.apk` и опубликуйте её вместе с исходниками в основной ветке. Создайте GitHub Release с тегом `v<versionName>` на этом коммите. В описании релиза укажите ссылку на APK по тегу и пометьте актуальную стабильную версию как Latest. Проверьте, что файл по постоянной ссылке из README имеет ту же контрольную сумму SHA-256, что и локальный APK.
