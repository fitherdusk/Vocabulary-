# Публикация APK

Публикуйте исходники и устанавливаемый APK в репозитории `fitherdusk/Vocabulary-` на GitHub.

Для каждой версии проверьте номер версии и подпись APK, отправьте исходники в репозиторий и создайте GitHub Release с тегом `v<versionName>` на соответствующем коммите. Прикрепите APK под постоянным именем `OfflineVocabulary.apk` и пометьте актуальную стабильную версию как Latest. После публикации проверьте, что файл по постоянной ссылке имеет ту же контрольную сумму SHA-256, что и локальный APK.
