# Offline Vocabulary

made by ai

Нативное Android-приложение для изучения слов по карточкам и интервальным повторениям. Минимальная версия системы — Android 8.0 (API 26). Целевая версия — Android 15 (API 35). Интерфейс на русском языке.

## Первый запуск

При первом открытии приложение записывает в локальную базу словарь **«Частотный сербский»**. Он содержит **1917 уникальных слов** в исходном порядке. В первом предоставленном файле 999 непустых строк, во втором — 918. Оригинальные TXT включены в APK, в том числе строки с опечатками и смешением алфавитов. После удаления этого словаря приложение сохраняет выбор пользователя при последующих запусках.

Откройте «Начать». На лицевой стороне видны сербское слово и приблизительное чтение русскими буквами. Нажмите «Показать перевод», чтобы увидеть слово, чтение и перевод вместе, затем оцените свой ответ. Например, для «хвала» карточка показывает «хва́ла» и «спасибо». Кнопка со столбиками в верхней части главного экрана открывает статистику. Нажмите на название словаря, чтобы выбрать, переименовать или удалить его. Через «Добавить словарь» или нижнюю кнопку с плюсом можно открыть локальный файл.

### Переводы и произношение в версии 1.1

В 1895 карточках есть русское значение и подсказка по чтению. Для 15 записей с вероятной потерей диакритики указаны возможное словарное написание, его чтение и значение. Ещё у семи записей недостаточно контекста для уверенного толкования. Спорные записи сохраняют исходное написание и пропускаются в тестах с переводом. У подтверждённых слов составитель указывает значения самой формы, например «знам» — «знаю».

Русская запись помогает начать читать слово. Сербские «ћ» и «ч» приблизительно переданы через «ч», «ђ» и «џ» через «дж». Кириллица русского языка также не передаёт сербское музыкальное ударение и все различия долготы. В 842 подсказках отмечена позиция ударения по засвидетельствованной словоформе. В режиме ввода ответа можно ввести одно из значений, разделённых точкой с запятой.

Источники статей указаны для отдельных записей в столбце `references` файла `app/src/main/assets/mojsrpski/cards.tsv`. Русские значения и подсказки включены в APK и доступны офлайн. Лексическая таблица распространяется по CC BY-SA 4.0. [Подробно об источниках и атрибуции](app/src/main/assets/mojsrpski/SOURCES.txt) · [Текст лицензии](app/src/main/assets/mojsrpski/CC-BY-SA-4.0.txt)

При обновлении с версии 1.0 или восстановлении её копии приложение дополняет исходный встроенный словарь, включая переименованный. Идентификаторы слов, ответы, расписание и позиция занятия сохраняются.

## Установка APK

Скопируйте APK на телефон и откройте его в приложении «Файлы». Если Android запросит разрешение, разрешите установку из этого источника и нажмите «Установить». При включённой отладке по USB выполните на компьютере команду установки, указав имя скачанного файла.

```sh
adb install -r OfflineVocabulary.apk
```

Приложение использует внутреннюю SQLite и системный выбор документов. Разрешение на доступ к интернету отсутствует. Импорт, резервное копирование, просмотр PDF, обучение и первый запуск работают с файлами устройства. Ссылки выше приведены для проверки происхождения данных.

## Собственный словарь

1. Сохраните файл в памяти телефона и нажмите «Добавить словарь».
2. Введите название, проверьте первую строку и сопоставьте столбцы со словом, переводом, транскрипцией и примером. Обязателен только столбец слова.
3. Проверьте первые десять подготовленных записей и счётчики. Строки с пустым словом пропускаются. При поиске одинаковых пар «слово + перевод» приложение игнорирует регистр и лишние пробелы. Текст берётся из первого вхождения. Разные переводы одного слова можно оставить отдельными записями.
4. Нажмите «Импортировать словарь». Завершённый импорт выбирает новый словарь для занятия.

| Формат | Структура файла |
| --- | --- |
| TXT | Одно слово в строке, пары через дефис или тире с пробелами, поля через вертикальную черту или табуляцию. |
| CSV, TSV | Автоматическое распознавание запятой, точки с запятой, табуляции или вертикальной черты. Кавычки позволяют включить в поле разделитель и перенос строки. Двойная кавычка внутри поля записывается как `""`. |
| JSON | Массив строк, объектов или строк таблицы. Поддерживается также объект с массивом `words` или `entries`. Ключи объектов становятся столбцами предпросмотра. |
| JSONL, NDJSON | По одному JSON-значению в каждой непустой строке. Для записей с несколькими полями используйте объекты. |
| Markdown | Таблицы с вертикальными разделителями и строкой выравнивания, а также списки слов и пар. Расширения `.md` и `.markdown`. |
| DOCX | Обычные таблицы Word. В документах без таблиц используются абзацы. Извлечение локальное, через ZIP и разбор WordprocessingML средствами Android. |
| PDF | Текстовый слой читается PDFBox-Android. Для табличных документов результат зависит от размещения текста. Предпросмотр позволяет проверить разбиение. Для сканов требуется заранее подготовленный текстовый файл. |

Текстовые форматы используют UTF-8, в том числе с BOM. Заголовки `word`, `translation`, `transcription`, `example` и их русские аналоги распознаются автоматически. Порядок можно изменить вручную. Остальные заполненные поля сохраняются как дополнительные сведения.

### Примеры TXT

```text
hello - привет
world - мир
house - дом
```

```text
hello | привет | həˈləʊ | Hello, my friend.
```

```json
{"translation":"привет","word":"hello","example":"Hello, my friend."}
```

## Занятия и прогресс

- **Карточки.** Сначала идут назначенные повторения, затем новые слова в исходном или случайном порядке. Количество новых слов задаётся в настройках.
- **Тест.** У вопроса четыре разных варианта, среди которых один правильный. Альтернативный верный перевод того же слова исключается из ложных вариантов.
- **Ввод ответа.** Достаточно одной переведённой записи. Ответ проверяется по данным словаря с нормализацией регистра и пробелов. При нескольких записях для одной подсказки принимаются исходные варианты перевода.
- **Повторение.** Можно вернуться к уже встречавшимся словам, начиная с тех, чей срок повторения наступил раньше. Для него достаточно одного оценённого слова.

Приложение сохраняет очередь, порядок вариантов и каждый оценённый ответ в SQLite. «Назад» позволяет выйти из занятия и продолжить с той же позиции. При смене словаря или параметров, определяющих состав занятия, формируется новая очередь. Уже засчитанные ответы остаются в истории.

### Расписание

Используется адаптация SM-2 с тремя оценками. «Не знаю» увеличивает число ошибок, сбрасывает серию успешных ответов и назначает повторение через 10 минут. «Трудно» сбрасывает серию и назначает повторение на следующий календарный день. Последовательные ответы «Знаю» назначают интервалы 1 день, 6 дней, затем предыдущий интервал, умноженный на коэффициент лёгкости. При переходе на следующий день учитывается местный часовой пояс устройства.

Коэффициент начинается с 2,5. Для оценок 0, 3 и 5 применяется формула SM-2 `EF += 0.1 − (5−q) × (0.08 + (5−q) × 0.02)`, результат ограничен диапазоном 1,3–4,0. Слово считается изученным после трёх подряд ответов «Знаю». Занятие включает до 30 повторений и заданную в настройках порцию новых слов. Дневная цель учитывает число разных слов, оценённых за местный календарный день.

Экран статистики относится к выбранному словарю. В счётчик занятий входят занятия хотя бы с одним ответом. Серия сохраняется до конца текущего дня, если пользователь занимался вчера.

С версии 1.2 процент освоения словаря равен среднему проценту по всем его словам. Новое слово даёт 0%, ответ «Не знаю» или «Трудно» даёт 10%, а один, два и три ответа «Знаю» подряд дают 40%, 70% и 100% соответственно. Например, если вы впервые отметили «Знаю» для 10 слов из 1917, приложение покажет 0,21% освоения и 0 полностью изученных слов. Ранее сохранённые ответы учитываются сразу после обновления.

## Резервная копия

В «Настройках» выберите экспорт резервной копии и место в памяти телефона. Копия — локальный файл JSON с версией формата. Внутри сохраняются словари, история ответов, интервалы, настройки и незавершённое занятие.

Для переноса выберите файл через действие восстановления в тех же настройках. После подтверждения приложение заменит текущую библиотеку содержимым копии. Если чтение или проверка завершаются ошибкой, транзакция откатывается. Сброс прогресса одного словаря тоже требует подтверждения и сохраняет сами слова. Резервная копия содержит пользовательские данные в открытом виде.

## Сборка в Android Studio

1. Распакуйте архив проекта и откройте каталог `OfflineVocabulary`, в котором находится `settings.gradle.kts`.
2. Используйте Android Studio с поддержкой AGP 8.7.3, Gradle JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. При сборке из консоли укажите SDK через `ANDROID_HOME` или `sdk.dir` в локальном файле `local.properties`.
3. Выполните Gradle Sync. Доступ в сеть нужен компьютеру при первом получении Gradle и зависимостей. В Linux и macOS выполните команду из корня проекта.

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

В Windows используйте `gradlew.bat`. Путь к APK — `app/build/outputs/apk/debug/app-debug.apk`. Сборка `debug` автоматически подписывается локальным отладочным ключом Android. Для публикации или собственных обновлений используйте постоянный ключ подписи. Если на телефоне уже установлена сборка с другой подписью, экспортируйте данные перед её удалением.

В тестах используются JUnit и Robolectric. Первый запуск тестов может дополнительно получить образы Android для JVM. Кэш Gradle и SDK нужны только на компьютере разработчика.

## Структура проекта

| Путь от `app/src/main/` | Назначение |
| --- | --- |
| `assets/mojsrpski/` | Оригинальные TXT, переводы и русское чтение, ссылки на статьи и лицензия. |

```sh
./gradlew :app:connectedDebugAndroidTest
```
